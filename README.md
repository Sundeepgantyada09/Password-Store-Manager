# 🔐 Password Store Manager

A secure and user-friendly password management system built with **.NET (C#)** and **MySQL**. This desktop application allows users to safely store, retrieve, and manage passwords for various applications with built-in encryption and authentication mechanisms.

## 📌 Features

- User authentication and secure login.
- Create, view, update, and delete password entries.
- Random password generator for strong credential creation.
- Visual feedback for password correctness and alerts.
- Data persistence using MySQL database.
- Simple and intuitive user interface developed in Windows Forms.

## 🛠 Technologies Used

- .NET Framework (C#)
- MySQL Database
- Visual Studio
- Windows Forms (WinForms)
- SQL Connector / ADO.NET
